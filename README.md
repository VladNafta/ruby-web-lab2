# ЛР2. Специфікація вимог до ПЗ — онлайн-бібліотека «Читанка»

Дисципліна «Мови програмування для web», лабораторна робота № 2. Виконав Мельник В.Я., група ІП-23-2.

Базова версія (1.0) специфікації вимог (SRS) до веб-застосунку на Ruby on Rails, який розроблятиметься
в наступних лабораторних роботах. Структура — за планом методички (шаблон К. Вігерса на основі
IEEE Std 830-1998), зміст узгоджено з ISO/IEC/IEEE 29148:2018.

| Файл | Що це |
|---|---|
| [SRS.md](SRS.md) | Специфікація у Markdown (зручно читати на GitHub) |
| `SRS_Chytanka_v1.0.docx`, `.pdf` | Та сама специфікація для друку |
| `diagrams/*.mmd` | Вихідні файли діаграм (Mermaid): контекстна і ER |
| `mockups/index.html` | Каркасний макет головної сторінки з бічною панеллю |

Діаграми рендеряться будь-яким переглядачем Mermaid (наприклад, https://mermaid.live), макет — відкрити в браузері.
